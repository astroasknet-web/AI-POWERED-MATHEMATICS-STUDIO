# Course thumbnails

One 1920x1080 WebP (`public/course-thumbs/<slug>.webp`) and one 640x360 WebP (`<slug>-640.webp`) for every course in `lib/market/data/courses.json`,
plus `manifest.json` (id, exact title, file, size, concept, palette, colours, status).

The pictures are **drawn in code** (vector scenes rendered with `sharp`), not generated by an image model, so they are exact, repeatable and carry the real
title in real type. Each course has its own written concept (`concepts-*.mjs`) and its own scene (`scenes-*.mjs`), a palette, a layout and a background texture.

    node scripts/thumbs/build.mjs                  rebuild everything (about 2 minutes)
    node scripts/thumbs/build.mjs slug-a slug-b    only some courses
    node scripts/thumbs/build.mjs --sheet out.png  also write a contact sheet
    node scripts/thumbs/verify.mjs                 every course has both sizes, no two pictures alike

To add a course: add its entry to a `concepts-*.mjs` file and a scene to the matching `scenes-*.mjs`, then run the build. A course with no picture keeps the
generated vector cover in the app, so nothing breaks while it waits. Title type uses Segoe UI Black and Georgia (installed on the machine that builds).
